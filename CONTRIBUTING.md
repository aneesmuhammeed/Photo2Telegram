# Contributing to Photo2Telegram

First off, thank you for considering contributing to Photo2Telegram! It's people like you that make open-source tools better for everyone.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Include as much information as possible:
* Your iPhone model and iOS version.
* The version of the Shortcut you are using.
* Steps to reproduce the bug.
* Expected vs. actual behavior.

**Security Note:** Never include your Telegram Bot Token in an issue or screenshot!

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Open an issue on GitHub describing your idea, why it would be useful, and how it should work.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Make your changes to the Shortcut or documentation.
3. Test your changes thoroughly.
4. Ensure your updates do not break existing functionality (like duplicate prevention or Telegram integration).
5. Open a Pull Request! Please include a clear description of the problem you're solving or the feature you're adding.

## Testing Your Changes
Before submitting a Pull Request, please make sure you've tested your modified Shortcut with:
- Single photo uploads
- Multiple photo uploads
- Duplicate prevention (ensuring the 'Telegram Backup' album behaves correctly)

Please mention the iOS version you used for testing in your Pull Request.
